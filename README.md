# Portfolio Foundation

A personal portfolio foundation for Product Design/UI/UX and Video Editing.

## Tech stack

Next.js, React, TypeScript, Tailwind CSS, ESLint, and Prettier.

## Setup

- Install dependencies: `npm install`
- Start development: `npm run dev`
- Build: `npm run build`
- Lint: `npm run lint`
- Format: `npm run format`
