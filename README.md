# Fouzia Mahjabeen — Portfolio

Personal portfolio website of Fouzia Mahjabeen, a Product Designer and Video Editor with 5+ years of experience creating intuitive digital products, SaaS experiences, user interfaces, and engaging visual content.

The portfolio showcases selected product design projects, video editing work, professional experience, design capabilities, and contact information.

## Overview

This portfolio provides a concise view of:

- Product design and UX/UI design experience
- SaaS platforms, dashboards, and digital products
- Selected product design case studies
- Video editing and visual storytelling projects
- Design process, technical capabilities, and creative skills
- Resume and professional contact information

- Next.js — App Router

## Getting Started

Clone the repository:

```bash
git clone https://github.com/Fouziarais/Fouziarais.github.io.git
cd Fouziarais.github.io
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Available Scripts

### Development

```bash
npm run dev
```

Starts the local development server.

### Lint

```bash
npm run lint
```

Runs ESLint checks.

### Formatting

```bash
npm run format
```

Formats the project using Prettier.

### Formatting Check

```bash
npm run format:check
```

Checks whether the project is formatted correctly without modifying files.

### Production Build

```bash
npm run build
```

Creates the optimized production build.

### Production Server

```bash
npm run start
```

Starts the production build locally after running the build command.
